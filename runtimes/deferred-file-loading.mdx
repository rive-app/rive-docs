title: "Deferred File Loading"

---

import { Runtimes } from '/snippets/runtimes/landing-pages/runtimes.jsx'

Deferred file loading lets a Rive file decode its artboards, animations, and view model instances the first time you use them instead of while the file loads. This can shorten loading time for large files when you only use part of them.

Each runtime provides its own API for turning on deferred decoding.
