## Example Usage

<Demos examples={["cachingARiveFile"]} runtime="react"/>

Here’s a simplified example showing how to integrate the `useRiveFile` hook to reuse a `RiveFile` across components:

```javascript
import React, { useState } from 'react';
import { useRiveFile } from '@rive-app/react-canvas';

// Custom Wrapper component to display the Rive animation
const RiveAnimation = ({ riveFile }) => {
    const { RiveComponent } = useRive({
        riveFile: riveFile,
        autoplay: true
    });

    return <RiveComponent/>;
};

function App() {
const { riveFile, status } = useRiveFile({
    src: 'https://cdn.rive.app/animations/myrivefile.riv',
});

const [instanceCount] = useState(5); // Number of RiveAnimation components to render

if (status === 'idle') {
    return <div>Idle...</div>;
}

if (status === 'loading') {
    return <div>Loading...</div>;
}

if (status === 'failed') {
    return <div>Failed to load Rive file.</div>;
}

// Each RiveAnimation component uses the RiveFile we loaded earlier, so it is only fetched and initialized once
return (
    <div className="App">
        <header className="App-header">Rive Instances</header>
        <div className="rive-list">
        {Array.from({ length: instanceCount }, (_, index) => (
            <RiveAnimation key={`rive-instance-${index}`} riveFile={riveFile} />
        ))}
        </div>
    </div>
    );

}

export default App;
```

## GPU Canvas

A file imported for [GPU Canvas](/runtimes/react/gpu-canvas) cannot be shared the way the example above shares one across five components. GPU Canvas binds a file to a single `<canvas>`, so the first Rive component you pass it to claims that file for its lifetime.

Call `useRiveFile` inside each component that needs the same `.riv`, rather than hoisting one file to a parent:

```jsx highlight={4}
const RiveAnimation = () => {
  const { riveFile, status } = useRiveFile({
    src: 'my_file.riv',
    enableGPUCanvas: true,
  });

  const { RiveComponent } = useRive(
    status === 'success'
      ? { riveFile, autoplay: true, enableGPUCanvas: true }
      : null
  );

  return <RiveComponent />;
};
```

Each component imports the file separately. The `.riv` comes from the browser cache after the first fetch, so this costs a parse per component, usually not another network request.

If you do hoist one GPU Canvas file to several components, the runtime will warn once, then re-import the `.riv` implicitly and hand each additional Rive instance a fresh copy.

<Warning>
  The fallback means the file from `useRiveFile` **is genuinely not used** by those components. The fallback happens before Rive references the file, so it never touches your file. Rive draws entirely from the internal copy, which you have no handle on. This means any config you set up on the shared file applies only to the first Rive instance that claimed it.

  Treat the fallback as a safety net that keeps the canvas from going blank, not as a supported way to share a file. Call `useRiveFile` per component so you keep a handle on the file each one is actually drawing if that is important for your use case.
</Warning>

<Note>
  This only applies to files imported with `enableGPUCanvas: true`. Files imported without it can share across components.
</Note>

Because a file's rendering mode is fixed at import, `enableGPUCanvas` has to be set on `useRiveFile`. Setting that property only on `useRive` while passing a `riveFile` has no effect.
