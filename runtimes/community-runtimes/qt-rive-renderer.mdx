---
title: 'Qt Quick (Rive Renderer)'
description: "Rive's own GPU renderer in Qt Quick / QML, composited zero-copy into Qt's scene graph."
---

<Note>This is not a Rive owned or maintained project.</Note>

rive-qt-plugin adds a `RiveView` QML item that renders with the Rive Renderer itself, on the graphics device Qt already uses for the window (Metal, Direct3D 11/12, OpenGL or Vulkan), and hands the frame to Qt's scene graph without a copy. Feathering, blend modes and clipping render exactly as they do in Rive. It supports state machines, data binding, input, layout, audio and scripting on Qt 6.5+ for macOS, Windows and Linux.

- [Documentation](https://hypernuclear.com/docs/rive-qt/)
- [Getting started](https://hypernuclear.com/docs/rive-qt/getting-started/): add it to a CMake project and show your first `.riv`
- [Viewer](https://hypernuclear.com/docs/rive-qt/viewer/): open any `.riv` in Qt and try state machines, data binding and layout before writing code
- [QML API reference](https://hypernuclear.com/docs/rive-qt/qml-api/)
- [GitHub repository](https://github.com/hypernuclear/rive-qt-plugin)
