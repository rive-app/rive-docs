By default, Rive logs stay on the native side: Logcat on Android and `os_log` on iOS, through React Native's `RCTLog`. Nothing reaches JavaScript until you forward logs to the console or set a custom handler, so an app that doesn't opt in pays no JS cost per log line.

## Forwarding logs to the console

To see Rive logs in the JS console, call `forwardToConsole`:

```ts
import { RiveLog } from '@rive-app/react-native';

RiveLog.forwardToConsole();
```

Each message has a `[Rive/<tag>]` prefix. Debug and info logs use `console.log`. Warnings and errors both use `console.warn`, because `console.error` raises the error overlay in development for conditions apps usually can't act on. Errors you can handle reach your app through `onError` and rejected promises. See [error handling](/runtimes/react-native/error-handling).

## Setting the log level

Set the minimum log level with `setLogLevel`. Messages below this level are dropped, whether they go to the native log, the console, or a custom handler. The default level is `warn`.

```ts
import { RiveLog } from '@rive-app/react-native';

// Show all logs (debug, info, warn, error)
RiveLog.setLogLevel('debug');

// Only warnings and errors (the default)
RiveLog.setLogLevel('warn');

// Only errors
RiveLog.setLogLevel('error');
```

Available levels, from most to least verbose: `debug`, `info`, `warn`, `error`.

## Using a custom log handler

To route logs to your own logger, set a handler. Only one handler is active at a time, so `setHandler` and `forwardToConsole` each replace the current handler.

```ts
import { RiveLog } from '@rive-app/react-native';

RiveLog.setHandler((level, tag, message) => {
  // level: 'debug', 'info', 'warn', or 'error'
  // tag: the source of the log, such as 'Deprecation'
  myLogger.log(`[Rive/${tag}] ${message}`, level);
});
```

Tag names can differ between iOS and Android, so avoid matching on specific tags.

## Returning to native logging

To detach the current handler, including the one set by `forwardToConsole`, and send logs back to the native log:

```ts
RiveLog.resetHandler();
```
