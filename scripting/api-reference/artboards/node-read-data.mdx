---
title: NodeReadData
---

Represents a node in the hierarchy, providing transform properties and
access to parent and child nodes.


## Fields

### `position`

The local position of the node.
```lua highlight={4}
if self.instance then
  local node = self.instance:node('Hips')
  if node then
    node.position = Vector.xy(199, 299)
  end
end
```


### `rotation`

The local rotation of the node in radians.
```lua highlight={4}
if self.instance then
  local node = self.instance:node('Hips')
  if node then
    node.rotation = math.rad(45)
  end
end
```


### `scale`

The local scale of the node.
```lua highlight={4}
if self.instance then
  local node = self.instance:node('Hips')
  if node then
    node.scale = Vector.xy(1.4, 2)
  end
end
```


### `worldTransform`

The read-only world transform of the node.
```lua highlight={4,5,6,7}
if self.instance then
  local node = self.instance:node('Hips')
  if node then
    local wt = node.worldTransform
    print("world xx:", wt.xx, "xy:", wt.xy)
    print("world yx:", wt.yx, "yy:", wt.yy)
    print("world tx:", wt.tx, "ty:", wt.ty)
  end
end
```

### `paint`

The stroke or fill a path effect applies to, on the node its `update`
receives, otherwise nil. The same as `asPaint`.
```lua highlight={2}
function update(self: MyEffect, path: PathData, node: NodeReadData): PathData
  local paint = node.paint
  if paint then
    print(paint.color)
  end
  return path
end
```


## Methods

### `asPath`

{/* function asPath(self):  PathData? */}
<div class="signature">
```lua
asPath() -> PathData?
```
</div>

If node is a Path, returns the node as [PathData](/scripting/api-reference/path/path-data).
```lua highlight={5}
function pointerDown(self: PaintInstance, event: PointerEvent)
  if self.instance then
    local myPath = self.instance:node('MyPath')
    if myPath then
      local path = myPath:asPath()
      if path then
        local cmd: PathCommand = path[1]
        print(cmd.type) -- moveTo
      end
    end
  end
end
```


### `asPaint`

{/* function asPaint(self):  Paint? */}
<div class="signature">
```lua
asPaint() -> Paint?
```
</div>

Returns the stroke or fill a path effect applies to, on the node its
`update` receives, otherwise nil.
```lua highlight={2}
function update(self: MyEffect, path: PathData, node: NodeReadData): PathData
  local paint = node:asPaint()
  if paint then
    print(paint.thickness)
  end
  return path
end
```


### `bounds`

{/* function bounds(self): (Vector, Vector) */}
<div class="signature">
```lua
bounds() -> (Vector, Vector)
```
</div>

The node's own box in its local space, as its minimum and maximum
points: a layout's box, a shape's, path's or image's extent, a
text's layout box, the artboard a nested artboard shows. Both points
are zero for a node with no size of its own, such as a group or a
bone.
```lua highlight={4}
if self.instance then
  local button = self.instance:node('Button')
  if button then
    local min, max = button:bounds()
    print(max.x - min.x, max.y - min.y)
  end
end
```


### `worldBounds`

{/* function worldBounds(self): (Vector, Vector) */}
<div class="signature">
```lua
worldBounds() -> (Vector, Vector)
```
</div>

The node's box in its artboard's space: what `bounds` gives, through
the world transform, as the minimum and maximum points of the area
it covers. A node with no size of its own covers just its origin.
```lua highlight={4}
if self.instance then
  local menu = self.instance:node('Menu')
  if menu then
    local min, max = menu:worldBounds()
    local p = Vector.xy(120, 40)
    print(p.x >= min.x and p.x <= max.x and p.y >= min.y and p.y <= max.y)
  end
end
```
