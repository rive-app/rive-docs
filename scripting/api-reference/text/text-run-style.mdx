---
title: TextRunStyle
---

Style of one run appended to a [Text](/scripting/api-reference/text/text).


## Fields

### `font`

### `size`

Font size, 16 when omitted.


### `lineHeight`

Line height, the font's own when omitted.


### `letterSpacing`

### `paint`

Runs sharing a paint draw as one path. A run without a paint only
draws when `Text:draw` is given one.


### `foregroundColor`

Color used by emoji layers that take the text color.


### `highlight`

Fills the line box behind the run's glyphs. Drawn first, and always
with this paint, even when `Text:draw` is given one.


### `underline`

Draws a line under the run, placed and sized by its font, behind the
glyphs.


### `strikethrough`

Draws a line through the run, placed and sized by its font, over the
glyphs.
