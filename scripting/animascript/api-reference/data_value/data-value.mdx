---
title: DataValue
---

Base type for the values a [Converter](/scripting/animascript/api-reference/host/converter) converts between. Check the kind
with the `is` methods or narrow with `instanceof`, then read `value` on
the subclass.

```as
export class Doubler extends Converter {
    override convert(input: DataValue): DataValue? {
        if (input instanceof DataValueNumber) {
            return DataValue.newNumber(input.value * 2);
        }
        return null;
    }
}
```
