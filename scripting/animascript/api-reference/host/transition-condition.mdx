---
title: TransitionCondition
---

A condition a transition between state machine states must meet to be
taken.

It inherits `init`, `advance` and `dispose` from [Protocol](/scripting/animascript/api-reference/host/protocol).
```as
export class WhenReady extends TransitionCondition {
    @input ready: bool = false;

    override evaluate(): bool {
        return this.ready;
    }
}
```


## Methods

### `evaluate`

<div class="signature">
```as
abstract evaluate(): bool
```
</div>

Called every frame while the transition is active. Return true to
allow the transition, or false to prevent it.
