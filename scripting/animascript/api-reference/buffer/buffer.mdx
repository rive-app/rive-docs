title: Buffer
---

Reads and writes binary data in an `ArrayBuffer`, such as file contents or
packed vertex data.

Offsets are byte positions starting at 0. Offsets, counts and values are
`f64` and truncated to integers. Integer writes keep the low bits of the
value, so `writeu8` with 256 stores 0. An access that reaches outside the
buffer throws `"buffer access out of bounds"`, as in Luau.
```ts
import { Buffer } from "rive/buffer";

export function roundTrip(): f64 {
  let b = Buffer.create(8);
  Buffer.writeu16(b, 0, 513);
  Buffer.writef32(b, 4, 1.5);
  return Buffer.readu16(b, 0) + Buffer.readf32(b, 4);
}
```

### `copy`

<div class="signature">
```ts
function copy(target: ArrayBuffer, targetOffset: f64, source: ArrayBuffer, sourceOffset: f64 = 0, count: f64 = NaN): void
```
</div>

Copies `count` bytes from `source` at `sourceOffset` into `target` at
`targetOffset`. Without `count`, copies to the end of `source`. The
ranges may overlap.


### `fill`

<div class="signature">
```ts
function fill(b: ArrayBuffer, offset: f64, value: f64, count: f64 = NaN): void
```
</div>

Sets `count` bytes of `b` from `offset` to `value`, truncated to a byte.
Without `count`, fills to the end of `b`.


### `readbits`

<div class="signature">
```ts
function readbits(b: ArrayBuffer, bitOffset: f64, bitCount: f64): f64
```
</div>

Reads `bitCount` bits, 0 to 32, starting `bitOffset` bits into `b`, as
an unsigned integer. Bits count from the lowest bit of each byte, and
bytes in order, so a read can span byte boundaries.
```ts
import { Buffer } from "rive/buffer";

export function nibble(): f64 {
  let b = Buffer.create(1);
  Buffer.writeu8(b, 0, 0xa5);
  return Buffer.readbits(b, 4, 4); // 0xa
}
```


### `writebits`

<div class="signature">
```ts
function writebits(b: ArrayBuffer, bitOffset: f64, bitCount: f64, value: f64): void
```
</div>

Writes the low `bitCount` bits, 0 to 32, of `value` starting `bitOffset`
bits into `b`, leaving the bits around them unchanged. Bits are laid
out as in `readbits`.

### `readstring`

<div class="signature">
```ts
function readstring(b: ArrayBuffer, offset: f64, count: f64): string
```
</div>

Decodes `count` bytes at `offset` as UTF-8 text. Throws for a negative
count.


### `writestring`

<div class="signature">
```ts
function writestring(b: ArrayBuffer, offset: f64, text: string, count: f64 = NaN): void
```
</div>

Writes `text` encoded as UTF-8 at `offset`. With `count`, writes only
that many bytes of the encoding; a count past the end of the encoding
throws.
