---
title: StrokeJoin
---

How two stroke segments are joined at a corner.
```as
let paint = new Paint();
paint.color = Color.rgb(255, 100, 50);
paint.style = PaintStyle.stroke;
paint.join = StrokeJoin.round;
```


## Fields

### `miter`

Sharp corner.


### `round`

Rounded corner.


### `bevel`

Flattened corner.
