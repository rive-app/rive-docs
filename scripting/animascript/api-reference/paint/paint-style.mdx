---
title: PaintStyle
---

Whether a [Paint](/scripting/animascript/api-reference/paint/paint) fills a shape or strokes its outline.
```ts
let paint = new Paint();
paint.color = Color.rgb(255, 100, 50);
paint.style = PaintStyle.stroke;
```


## Fields

### `stroke`

Draws the outline of the shape.


### `fill`

Fills the inside of the shape.
