---
title: StrokeCap
---

The shape at the ends of open stroke segments.
```as
let paint = new Paint();
paint.color = Color.rgb(255, 100, 50);
paint.style = PaintStyle.stroke;
paint.cap = StrokeCap.round;
```


## Fields

### `butt`

Squared end with no extension.


### `round`

Semicircular cap.


### `square`

Squared cap that extends past the end point.
