---
title: DataContext
---

A level of the data context hierarchy and its [ViewModel](/scripting/animascript/api-reference/data/view-model). Get the one
bound to a script with `Context.dataContext`.


## Methods

### `parent`

<div class="signature">
```as
parent(): DataContext?
```
</div>

The parent data context, or null at the top.

```as
let dc = context.dataContext();
if (dc != null) {
    let parent = dc.parent();
    let vm = dc.viewModel();
}
```


### `viewModel`

<div class="signature">
```as
viewModel(): ViewModel?
```
</div>

The view model bound to this context, or null when there is none.
