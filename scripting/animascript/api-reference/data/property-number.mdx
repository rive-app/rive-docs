A number property of a view model.


## Fields

### `value`

<div class="signature">
```ts
value: f64
```
</div>

The current value. You can both read and assign it.

```ts
let health = vm.getNumber("health");
if (health != null) {
    console.log(health.value.toString());
    health.value = 100;
}
```
