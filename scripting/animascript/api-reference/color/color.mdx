---
title: Color
---

A color packed into a `u32` as 0xAARRGGBB, alpha in the top byte.

Build colors with the helpers on [Color](/scripting/animascript/api-reference/color/color) or write the hex value directly.
```ts
let red: Color = Color.rgb(255, 0, 0);
let halfRed: Color = 0x80ff0000;
```


## Static Functions

### `argb`

<div class="signature">
```ts
function argb(a: i32, r: i32, g: i32, b: i32): Color
```
</div>

Returns a color built from alpha, red, green and blue channels, each 0 to
255. Only the low 8 bits are kept, so 300 becomes 44 and -1 becomes 255.
```ts
// Red at 50% opacity
let color = Color.argb(128, 255, 0, 0);
```


### `rgb`

<div class="signature">
```ts
function rgb(r: i32, g: i32, b: i32): Color
```
</div>

Returns a fully opaque color built from red, green and blue channels, each 0
to 255. Only the low 8 bits are kept, so 300 becomes 44 and -1 becomes 255.
```ts
// Red
let color = Color.rgb(255, 0, 0);
```


### `rgba`

<div class="signature">
```ts
function rgba(r: i32, g: i32, b: i32, a: i32): Color
```
</div>

Returns a color built from red, green, blue and alpha channels, each 0 to
255. Only the low 8 bits are kept, so 300 becomes 44 and -1 becomes 255.
```ts
// Red at 50% opacity
let color = Color.rgba(255, 0, 0, 128);
```

### `withRed`

<div class="signature">
```ts
function withRed(color: Color, value: i32): Color
```
</div>

Returns a copy of `color` with its red channel set to `value`, 0 to 255.
Only the low 8 bits are kept.
```ts
let myColor = Color.rgba(128, 55, 12, 128);
let newColor = Color.withRed(myColor, 200);
let channel = Color.red(newColor); // 200
```

### `opacity`

<div class="signature">
```ts
function opacity(color: Color): f32
```
</div>

Returns the opacity of `color` as a value from 0 to 1.
```ts
let myColor = Color.rgba(255, 0, 0, 128);
let myOpacity = Color.opacity(myColor); // about 0.5
```


### `opacityToAlpha`

<div class="signature">
```ts
function opacityToAlpha(opacity: f32): u32
```
</div>

Converts an opacity from 0 to 1 into an alpha channel from 0 to 255,
clamping out of range values.
```ts
let alpha = Color.opacityToAlpha(0.5); // 128
```


### `withOpacity`

<div class="signature">
```ts
function withOpacity(color: Color, value: f32): Color
```
</div>

Returns a copy of `color` with its alpha set from an opacity from 0 to 1.
Out of range values are clamped.
```ts
let myColor = Color.rgba(255, 0, 0, 128);
let opaque = Color.withOpacity(myColor, 1.0);
let myOpacity = Color.opacity(opaque); // 1
```


### `lerp`

<div class="signature">
```ts
function lerp(from: Color, to: Color, mix: f32): Color
```
</div>

Linearly interpolates each channel between two colors, where a `mix` of 0
returns `from` and 1 returns `to`.
```ts
let black = Color.rgb(0, 0, 0);
let white = Color.rgb(255, 255, 255);

// Halfway between black and white
let gray = Color.lerp(black, white, 0.5);
```


### `toFloat`

<div class="signature">
```ts
function toFloat(color: Color): StaticArray<f32>
```
</div>

Converts `color` into four floats, red, green, blue and alpha, each from 0
to 1. Useful for the clear values of a [GPUColorAttachment](/scripting/animascript/api-reference/gpu/gpu-color-attachment).
```ts
let channels = Color.toFloat(Color.rgba(255, 0, 0, 128));
// [1.0, 0.0, 0.0, 0.502]
```
