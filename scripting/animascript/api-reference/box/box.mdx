---
title: Box
---

A class that holds one value, so a value that cannot be null on its own can
be optional. Numbers, booleans and structs are never null, so an optional
one is written `Box<T>?`: `null` means no value.

Structs cannot be generic arguments, so use [Box_Vector](/scripting/animascript/api-reference/box/box_vector) and [Box_Mat2D](/scripting/animascript/api-reference/box/box_mat2d) for
[Vector](/scripting/animascript/api-reference/vector/vector) and [Mat2D](/scripting/animascript/api-reference/mat2d/mat2d).
```as
import { Box } from "rive/box";

function half(value: f64): Box<f64>? {
  return value > 0 ? new Box<f64>(value / 2) : null;
}

export function describe(value: f64): string {
  return half(value)?.value.toString() ?? "none";
}
```
