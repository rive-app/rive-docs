title: PathMeasure
---

Measures a path, or one contour of it, and samples points along it.


## Fields

### `length`

<div class="signature">
```as
readonly length: f64
```
</div>

The total length of the measured path across all contours, or of the
one contour for a [ContourMeasure](/scripting/animascript/api-reference/path/contour-measure).
```as
let path = new Path();
path.moveTo(Vector.xy(-150, 0));
path.cubicTo(Vector.xy(-80, -120), Vector.xy(80, 120), Vector.xy(150, 0));

let measure = path.measure();
console.log("length: " + measure.length.toString());
```


### `isClosed`

<div class="signature">
```as
readonly isClosed: bool
```
</div>

True only if the path has exactly one contour and that contour is closed.
Paths with several contours are never closed, even when every contour is.
For a [ContourMeasure](/scripting/animascript/api-reference/path/contour-measure), whether its contour is closed.
```as
let measure = path.measure();
let closed = measure.isClosed;
```


## Methods

### `positionAndTangent`

<div class="signature">
```as
unsafe positionAndTangent(distance: f64): PosTan
```
</div>

Returns the position and normalized tangent at `distance` along the path.
The distance is clamped between 0 and `length`.
```as
override draw(renderer: Renderer): void {
  renderer.drawPath(this.path, this.pathPaint);

  // Place a dot that travels along the path
  let measure = this.path.measure();
  let distance = (this.elapsed * 0.3) % 1.0 * measure.length;
  let pos = measure.positionAndTangent(distance).v0;

  this.traveler.reset();
  drawDot(this.traveler, pos.x, pos.y, 8);
  renderer.drawPath(this.traveler, this.travelerPaint);
}
```


### `warp`

<div class="signature">
```as
unsafe warp(source: Vector): Vector
```
</div>

Warps a point onto the path: `source.x` is a distance along the path and
`source.y` an offset along the normal there. Returns the warped position.
```as
// Map a grid of points onto the path, x as distance and y as offset
let measure = this.path.measure();
let len = measure.length;
this.warpPath.reset();
let cols = 16;
let rows = 3;
for (let col = 0; col <= cols; col++) {
  for (let row = -rows; row <= rows; row++) {
    let source = Vector.xy(<f32>(<f64>col / <f64>cols * len), <f32>(row * 20));
    let warped = measure.warp(source);
    drawDot(this.warpPath, warped.x, warped.y, 3);
  }
}
renderer.drawPath(this.warpPath, this.warpPaint);
```


### `extract`

<div class="signature">
```as
unsafe extract(startDistance: f64, endDistance: f64, destination: Path, startWithMove: bool = true): void
```
</div>

Appends the section of the path between `startDistance` and `endDistance`
to `destination`. Distances are clamped between 0 and `length`. When
`startWithMove` is true, the default, the section starts with a `moveTo`;
otherwise it continues from the last point of `destination`.
```as
// A highlight window traveling along the path
let measure = this.path.measure();
let len = measure.length;
let start = (this.elapsed * 0.3) % 1.0 * len;
let end = start + len * 0.4;
this.extractedPath.reset();
if (end <= len) {
  measure.extract(start, end, this.extractedPath);
} else {
  // Wrap around the end of the path
  measure.extract(start, len, this.extractedPath);
  measure.extract(0, end - len, this.extractedPath, false);
}
renderer.drawPath(this.extractedPath, this.extractPaint);
```


### `release`

<div class="signature">
```as
release(): void
```
</div>

Frees the measure's host resources now instead of when it is collected. Do
not use the measure afterwards.
