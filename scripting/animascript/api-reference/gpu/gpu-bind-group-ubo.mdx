---
title: GPUBindGroupUBO
---

A uniform buffer entry of a [GPUBindGroup](/scripting/animascript/api-reference/gpu/gpu-bind-group). The bound range must cover
the shader's uniform block, or the [GPUBindGroup](/scripting/animascript/api-reference/gpu/gpu-bind-group) constructor raises an
error.


## Fields

### `slot`

<div class="signature">
```as
slot: u32
```
</div>

WGSL `@binding` of the uniform buffer.


### `buffer`

<div class="signature">
```as
buffer: GPUBuffer
```
</div>

The buffer to bind.


### `offset`

<div class="signature">
```as
offset: u32
```
</div>

Byte offset of the bound range.


### `size`

<div class="signature">
```as
size: u32
```
</div>

Byte size of the bound range. Zero binds the rest of the buffer past
`offset`.


## Constructors

### `constructor`

<div class="signature">
```as
constructor(slot: u32, buffer: GPUBuffer, offset: u32 = 0, size: u32 = 0)
```
</div>

Creates an entry binding `buffer` at `slot`.
