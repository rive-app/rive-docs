---
title: GPUTextureViewDesc
---

Descriptor for `GPUTexture.view`, selecting a sub range of the texture.
The defaults describe the whole texture.


## Fields

### `dimension`

<div class="signature">
```as
dimension: TextureViewDimension
```
</div>

Reinterprets the texture as another dimensionality. Defaults to the
texture's own type.


### `aspect`

<div class="signature">
```as
aspect: TextureAspect
```
</div>

Planes to expose for a depth stencil texture. Default `all`; use
`depthOnly` for `texture_depth_2d` in WGSL.


### `baseMipLevel`

<div class="signature">
```as
baseMipLevel: u32
```
</div>

First mip level. Default 0.


### `mipCount`

<div class="signature">
```as
mipCount: u32
```
</div>

Number of mip levels. Zero, the default, takes all remaining levels.


### `baseLayer`

<div class="signature">
```as
baseLayer: u32
```
</div>

First array layer or cube face. Default 0.


### `layerCount`

<div class="signature">
```as
layerCount: u32
```
</div>

Number of layers or faces. Zero, the default, takes all remaining
layers.
