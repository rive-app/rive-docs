## Methods

### `view`

<div class="signature">
```ts
unsafe view(desc: GPUTextureViewDesc = new GPUTextureViewDesc()): GPUTextureView
```
</div>

Creates a view into a sub range of this texture; omit `desc` for the
whole texture. Views are immutable. Create them once next to the
texture and reuse them every frame; calling `view` in `draw` creates
and destroys a native GPU object each frame.


### `upload`

<div class="signature">
```ts
unsafe upload(region: rive_gpu_texture_upload_v1, data: ArrayBuffer): void
```
</div>

Uploads raw pixel bytes in the texture's format into one region of a mip
level and layer. `region` is a `rive_gpu_texture_upload_v1` from
`rive/bindings`, all zero when created:

* `mipLevel`, `layer`, `x`, `y` and `z` place the region.
* `width`, `height` and `depth` size it; zero covers the rest of the
  mip from the origin.
* `bytesPerRow` and `rowsPerImage` describe the layout of `data`; zero
  means tightly packed. Block compressed formats need an explicit
  `bytesPerRow`.

Raises an error when the region falls outside the texture.

```ts
let region = new rive_gpu_texture_upload_v1();
region.width = 4;
region.height = 4;
texture.upload(region, pixels);
```


### `release`

<div class="signature">
