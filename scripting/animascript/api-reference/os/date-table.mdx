title: DateTable
---

A date and time broken into calendar fields, as returned by `dateTable`.


## Fields

### `sec`

<div class="signature">
```ts
sec: i32
```
</div>

Seconds, 0 to 59.


### `min`

<div class="signature">
```ts
min: i32
```
</div>

Minutes, 0 to 59.


### `hour`

<div class="signature">
```ts
hour: i32
```
</div>

Hours, 0 to 23.


### `day`

<div class="signature">
```ts
day: i32
```
</div>

Day of the month, 1 to 31.


### `month`

<div class="signature">
```ts
month: i32
```
</div>

Month, 1 for January to 12 for December.


### `year`

<div class="signature">
```ts
year: i32
```
</div>

The full year, such as 2026.


### `wday`

<div class="signature">
```ts
wday: i32
```
</div>

Day of the week, 0 for Sunday to 6 for Saturday.


### `yday`

<div class="signature">
```ts
yday: i32
```
</div>

Day of the year, 0 for January 1st.


### `isdst`

<div class="signature">
```ts
isdst: bool
```
</div>

True when daylight saving time is in effect. Always false in UTC.
