---
title: Mat4
---

A 4x4 column-major transformation matrix, suitable for 3D transforms and
direct upload to a GPU uniform buffer. Projections are right-handed and
map depth to the [0, 1] range. `new Mat4()` is all zeros, so start from
`Mat4.identity()` or one of the builders.
```as
// Construct a model-view-projection matrix
let proj = Mat4.perspective(Mathf.PI / 3, 16.0 / 9.0, 0.1, 100);
let view = Mat4.fromTranslation(0, 0, -3); // camera 3 units back
let model = Mat4.fromRotationY(0.5);
let mvp = proj * view * model;

// Upload to a uniform buffer (64 bytes, column-major)
let ubo = new ArrayBuffer(64);
mvp.writeToBuffer(ubo, 0);
```


## Fields

### `m`

<div class="signature">
```as
m: StaticArray<f32>
```
</div>

The 16 entries in column-major order: indices 0 to 3 are column 0,
4 to 7 column 1, 8 to 11 column 2 and 12 to 15 column 3, the
translation.
```as
let m = Mat4.identity();
m.m[12] = 50; // translate x
m.m[13] = 100; // translate y
m.m[14] = 25; // translate z
```


### `m11`

<div class="signature">
```as
m11: f32
```
</div>

The entry at row R, column C, both counted from 1, so `m12` is row
1, column 2. `m14`, `m24` and `m34` are the translation.
```as
let m = Mat4.identity();
m.m11 = 2; // scale x
m.m22 = 3; // scale y
m.m14 = 50; // translate x
```

## Static Functions

### `operator*`

<div class="signature">
```as
static operator*(a: Mat4, b: Mat4): Mat4
```
</div>

Returns the matrix product of two matrices as a new [Mat4](/scripting/animascript/api-reference/mat4/mat4), for
composing transforms such as `proj * view * model`. In tight loops
prefer `Mat4.multiply` to reuse storage.
```as
let m = Mat4.fromTranslation(10, 0, 0) * Mat4.fromScale(2, 2, 2);
let p = m.transformPoint(1, 1, 1); // 12 2 2
```


### `operator==`

<div class="signature">



### `perspective`

<div class="signature">
```as
static perspective(fovYRadians: f32, aspect: f32, near: f32, far: f32): Mat4
```
</div>

Creates a right-handed perspective projection matrix that maps z to
the [0, 1] depth range. `fovYRadians` is the vertical field of view;
`near` and `far` are positive distances.
```as
let proj = Mat4.perspective(Mathf.PI / 3, 16.0 / 9.0, 0.1, 100);
```


### `perspectiveReverseZ`

<div class="signature">
```as
static perspectiveReverseZ(fovYRadians: f32, aspect: f32, near: f32): Mat4
```
</div>

Creates a right-handed perspective projection with reverse Z, near
mapping to 1 and far to 0, and an infinite far plane. With a float
depth buffer this gives a near uniform depth precision across the
whole frustum. Clear the depth buffer to 0, not 1, and use the
`greater` depth test.
```as
let proj = Mat4.perspectiveReverseZ(Mathf.PI / 3, 16.0 / 9.0, 0.1);
```

### `multiply`

<div class="signature">
```as
static multiply(out: Mat4, a: Mat4, b: Mat4): Mat4
```
</div>

Writes `a * b` into `out`, reusing its storage, and returns `out`. Use
this in tight loops to avoid allocating a new [Mat4](/scripting/animascript/api-reference/mat4/mat4) per
multiplication. `out` may be `a` or `b`.
```as
let view = Mat4.lookAt(0, 0, 3, 0, 0, 0, 0, 1, 0);
let model = Mat4.identity();
let out = Mat4.identity();
for (let i = 0; i < 1000; i++) {
    Mat4.multiply(out, view, model);
}
```


### `multiplyAffine`

<div class="signature">
```as
static multiplyAffine(out: Mat4, a: Mat4, b: Mat4): Mat4
```
</div>

Like `Mat4.multiply`, but assumes both inputs are affine, with a
bottom row of [0, 0, 0, 1]. Any composition of translation, scale and
rotation matrices qualifies. Skips the bottom row work and always
returns an affine result; a non-affine input gives a wrong result.
`out` may be `a` or `b`.
```as
let parent = Mat4.fromTranslation(0, 1, 0);
let child = Mat4.fromRotationZ(0.5);
let world = Mat4.identity();
Mat4.multiplyAffine(world, parent, child);
```


### `invert`

<div class="signature">
```as
static invert(out: Mat4, src: Mat4): bool
```
</div>

Writes the inverse of `src` into `out` and returns true, or returns
false and leaves `out` unchanged when `src` is singular.
```as
let m = Mat4.lookAt(0, 2, 5, 0, 0, 0, 0, 1, 0);
let inv = Mat4.identity();
let ok = Mat4.invert(inv, m);
```


### `invertAffine`

<div class="signature">
```as
static invertAffine(out: Mat4, src: Mat4): bool
```
</div>

Like `Mat4.invert`, but only for affine matrices, with a bottom row
of [0, 0, 0, 1]; any composition of translation, scale and rotation
matrices qualifies. Faster than the full inverse. Returns false and
leaves `out` unchanged when the linear part is singular. `out` may be
`src`.
```as
let m = Mat4.fromTranslation(3, -4, 5) * Mat4.fromRotationY(0.4);
let inv = Mat4.identity();
let ok = Mat4.invertAffine(inv, m); // true
```


## Methods

### `operator[]`

<div class="signature">
```as
operator[](index: i32): f32
```
</div>

Returns the entry at column-major `index`, 0 to 15, the same entry as
`m[index]`.
```as
let m = Mat4.fromTranslation(50, 100, 25);
let tx = m[12]; // 50
```


### `operator[]=`

<div class="signature">
```as
operator[]=(index: i32, value: f32): void
```
</div>

Sets the entry at column-major `index`, 0 to 15.
```as
let m = Mat4.identity();
m[12] = 50; // translate x
```


### `mul`

<div class="signature">
```as
mul(rhs: Mat4): Mat4
```
</div>

Returns the matrix product of this matrix and `rhs` as a new [Mat4](/scripting/animascript/api-reference/mat4/mat4).
Useful for composing transforms, for example
`proj.mul(view).mul(model)`. In tight loops prefer `Mat4.multiply` to
reuse storage.


### `transformVec4`

<div class="signature">
```as
transformVec4(out: StaticArray<f32>, x: f32, y: f32, z: f32, w: f32): void
```
</div>

Transforms the homogeneous 4D vector (`x`, `y`, `z`, `w`) by the
matrix and writes the four result components into `out`, without a
perspective divide. Use it when you need the homogeneous w, for
example for clip space coordinates.
```as
let mvp = Mat4.perspective(Mathf.PI / 3, 1, 0.1, 100);
let clip = new StaticArray<f32>(4);
mvp.transformVec4(clip, 1, 2, -5, 1);
let w = clip[3];
```


### `transformPoint`

<div class="signature">
```as
transformPoint(x: f32, y: f32, z: f32): Vector
```
</div>

Transforms the 3D point (`x`, `y`, `z`) by the matrix, treating w as
1. When the resulting w is neither 0 nor 1, as after a perspective
matrix, the point is divided through by it.
```as
let m = Mat4.fromTranslation(10, 20, 30);
let p = m.transformPoint(1, 2, 3); // 11 22 33
```


### `transpose`

<div class="signature">
```as
transpose(): Mat4
```
</div>

Returns the transpose of the matrix.
```as
let t = Mat4.fromTranslation(1, 2, 3).transpose();
let bottomLeft = t.m41; // 1
```


### `writeToBuffer`

<div class="signature">
```as
unsafe writeToBuffer(buffer: ArrayBuffer, byteOffset: u32): void
```
</div>

Writes the matrix as 64 bytes, 16 column-major 32 bit floats, into
`buffer` at `byteOffset`. Throws when the 64 bytes do not fit.
```as
let ubo = new ArrayBuffer(64);
Mat4.identity().writeToBuffer(ubo, 0);
```


### `invert`

<div class="signature">
```as
invert(): Mat4 | null
```
</div>

Returns the inverse of the matrix, or null when it is singular.
```as
let inv = Mat4.fromTranslation(50, 100, 25).invert();
if (inv != null) {
    let p = inv.transformPoint(50, 100, 25); // 0 0 0
}
```


### `invertAffine`

<div class="signature">
```as
invertAffine(): Mat4 | null
```
</div>

Returns the affine inverse of the matrix, or null when its linear part
is singular. See `Mat4.invertAffine` for the contract.
```as
let m = Mat4.fromTranslation(3, -4, 5) * Mat4.fromRotationY(0.4);
let inv = m.invertAffine();
```
