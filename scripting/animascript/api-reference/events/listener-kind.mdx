---
title: ListenerKind
---

What triggered a listener action, read from `ListenerContext.kind`.


## Fields

### `pointer`

A pointer event.


### `keyboard`

A keyboard event.


### `textInput`

A text input event.


### `focus`

A focus change.


### `reportedEvent`

A reported Rive event.


### `viewModelChange`

A view model change.


### `none`

An unknown or unsupported event.


### `gamepadConnected`

A gamepad connected.


### `gamepadEvent`

A gamepad button or axis changed.


### `gamepadDisconnected`

A gamepad disconnected.


### `semantic`

A semantic action: a tap, increase or decrease.
