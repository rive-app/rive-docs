---
title: GamepadEvent
---

A gamepad's full state, delivered when a device connects, when one of its
buttons or axes changes, and when it disconnects. `kind` says which.

Button and axis indices are 0 based W3C Standard Gamepad slots. The named
reads such as `south` or `leftStick` answer only when `isStandardMapping`
is true, and read false or 0 otherwise; read any other device by index.
```as
override gamepadEvent(event: GamepadEvent): bool {
    if (event.south) {
        this.jump = true;
        return true;
    }
    this.move = event.leftStick;
    return false;
}
```

Why the event fired: `connected`, `event` or `disconnected`.


### `deviceId`

<div class="signature">
```as

```
</div>

A stable id for this device for as long as it stays connected.


### `gamepadMapping`

<div class="signature">
```as

```
</div>

The raw mapping value: 0 for the standard layout, 1 for unknown.


### `changeKind`

<div class="signature">

</div>

What changed on an `event`: `button` or `axis`. Empty for the
other kinds.


### `changeIndex`

<div class="signature">
```as

```
</div>

The 0 based index of the button or axis that changed.


### `changeValue`

<div class="signature">
```as

```
</div>

The new value of the button or axis that changed.


### `hasStandardButtonIntent`

<div class="signature">
```as

```
</div>

True when the change maps to a standard layout button, named by
`intentButton`.


### `standardButton`

<div class="signature">
```as

```
</div>

The 0 based standard button index behind `intentButton`, valid when
`hasStandardButtonIntent` is true.


### `hasStandardAxisIntent`

<div class="signature">
```as

```
</div>

### `standardAxis`

<div class="signature">
```as

```

The 0 based standard axis index behind `intentAxis`, valid when
`hasStandardAxisIntent` is true.


### `buttons`

<div class="signature">
```as
buttons: StaticArray<f32>
```
</div>

The analog value of every button, from 0 to 1, by 0 based W3C index.


### `axes`

<div class="signature">
```as
axes: StaticArray<f32>
```
</div>

The value of every axis by 0 based W3C index. The standard layout
has at least six: the two sticks, then the two triggers.


### `buttonMask`

<div class="signature">
```as
readonly buttonMask: u64
```
</div>

Every button's pressed state as bits: bit `i` is set when the button at
index `i` is pressed.


### `isStandardMapping`

<div class="signature">
```as

```
</div>

True when the host normalized the device to the W3C standard layout.


### `mapping`

<div class="signature">
```as

```
</div>

The layout: `standard` or `unknown`. Named reads answer only on
`standard`.


### `intentButton`

<div class="signature">

The standard name of the button that changed, such as `south` or
`dpadUp`, or null when the change has no standard button intent.


### `intentAxis`

<div class="signature">

</div>

The standard name of the axis that changed, such as `leftX` or
`rightTriggerAxis`, or null when the change has no standard axis
intent.

## Methods

### `axis`

<div class="signature">
```as

```
</div>

The value of the axis at the given 0 based index, or 0 when the
device does not report it.


### `buttonValue`

<div class="signature">
```as
buttonValue(index: i32): f32
```
</div>

The analog value, from 0 to 1, of the button at the given 0 based
index, or 0 when the device does not report it.


### `buttonPressed`

<div class="signature">
```as
buttonPressed(index: i32): bool
```
</div>

True if the button at the given 0 based W3C index is pressed.
