---
title: KeyboardEvent
---

A keyboard interaction, delivered to `Node.keyboardEvent`.
```as
override keyboardEvent(event: KeyboardEvent): bool {
    if (event.phase == "down" && event.shift) {
        this.boost = true;
        return true;
    }
    return false;
}
```
