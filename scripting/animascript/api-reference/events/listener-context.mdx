---
title: ListenerContext
---

The event that triggered a listener action, passed to
`ListenerAction.performAction`.

It can hold a pointer, keyboard, text input, focus, gamepad, view model
change or reported event. Check the type with the `is` methods, or switch
on `kind`, and read the event with the matching `as` method.
```as
override performAction(context: ListenerContext): void {
    let pointer = context.asPointerEvent();
    if (pointer != null) {
        this.lastClick = pointer.position;
    }
}
```
