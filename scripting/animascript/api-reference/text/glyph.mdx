---
title: Glyph
---

One glyph placed by a [Text](/scripting/animascript/api-reference/text/text) layout, in the text's local space.


## Fields

### `id`

<div class="signature">
```as
id: u32
```
</div>

Glyph id within `font`.


### `textIndex`

<div class="signature">
```as
textIndex: i32
```
</div>

Zero based UTF-16 code unit index of the first character this glyph
draws.


### `x`

<div class="signature">
```as
x: f32
```
</div>

Horizontal pen position on the baseline, the shaper's offset
included.


### `y`

<div class="signature">
```as
y: f32
```
</div>

Vertical pen position on the baseline, the shaper's offset included.


### `advance`

<div class="signature">
```as
advance: f32
```
</div>

Horizontal distance the pen moves past this glyph.


### `isColor`

<div class="signature">
```as
isColor: bool
```
</div>

Whether this is a color glyph (emoji) drawn as layers rather than one
outline.


### `font`

<div class="signature">
```as
readonly font: Font
```
</div>

Font of the run the glyph belongs to.


### `size`

<div class="signature">
```as
readonly size: f32
```
</div>

Font size of the run the glyph belongs to.


### `direction`

<div class="signature">
```as
readonly direction: TextDirection
```
</div>

Direction of the run the glyph belongs to, `ltr` or `rtl`.


## Methods

### `transform`

<div class="signature">
```as
transform(): Mat2D
```
</div>

Places the 1 point outline from `Font.glyphPath` at this glyph's size
and position.


### `path`

<div class="signature">
```as
path(): Path
```
</div>

The outline placed by `transform`, as a new [Path](/scripting/animascript/api-reference/path/path).
