---
title: TextSizing
---

How a [Text](/scripting/animascript/api-reference/text/text) sizes its box.


## Fields

### `autoWidth`

The box grows to fit the text, which wraps only at newlines.


### `autoHeight`

The width is `maxWidth` and the height grows to fit the text.


### `fixed`

The box is `maxWidth` by `maxHeight`.
