---
title: FontAxis
---

A variable axis of a [Font](/scripting/animascript/api-reference/text/font), such as weight or width.


## Fields

### `tag`

<div class="signature">
```ts
tag: string
```
</div>

Four letter axis tag, for example "wght".


### `min`

<div class="signature">
```ts
min: f32
```
</div>

Smallest value the axis accepts.


### `default_`

<div class="signature">
```ts
default_: f32
```
</div>

Value the axis takes when not set.


### `max`

<div class="signature">
```ts
max: f32
```
</div>

Largest value the axis accepts.
