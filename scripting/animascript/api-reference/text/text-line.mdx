---
title: TextLine
---

One line of a [Text](/scripting/animascript/api-reference/text/text) after wrapping. Its glyphs come in visual order,
left to right, whatever the writing direction.
```as
let lines = text.lines();
for (let i = 0; i < lines.length; i++) {
    let glyphs = lines[i].glyphs();
    for (let g = 0; g < glyphs.length; g++) {
        let glyph = glyphs[g];
        renderer.save();
        renderer.transform(glyph.transform());
        renderer.drawPath(glyph.font.glyphPath(glyph.id), paint);
        renderer.restore();
    }
}
```
