---
title: ColorWriteMask
---

Channels a color target writes. Combine values with `|` as `u32` for
[GPUColorTargetDesc](/scripting/animascript/api-reference/gpu/gpu-color-target-desc).


## Fields

### `none`

Write no channels.


### `red`

Write red.


### `green`

Write green.


### `blue`

Write blue.


### `alpha`

Write alpha.


### `all`

Write every channel.
