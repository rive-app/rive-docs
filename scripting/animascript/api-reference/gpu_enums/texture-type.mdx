---
title: TextureType
---

Dimensionality of a [GPUTexture](/scripting/animascript/api-reference/gpu/gpu-texture). Some types need a feature from [GPUFeatures](/scripting/animascript/api-reference/gpu/gpu-features).


## Fields

### `texture2D`

A 2D texture.


### `cube`

A cube map with six faces.


### `texture3D`

A 3D texture. Needs the `texture3D` feature.


### `array2D`

An array of 2D layers. Needs the `textureArrays` feature.
