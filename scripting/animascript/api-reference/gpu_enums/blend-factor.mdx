---
title: BlendFactor
---

Factor a blend applies to the source or destination color or alpha.


## Fields

### `zero`

Zero.


### `one`

One.


### `srcColor`

The source color.


### `oneMinusSrcColor`

One minus the source color.


### `srcAlpha`

The source alpha.


### `oneMinusSrcAlpha`

One minus the source alpha.


### `dstColor`

The destination color.


### `oneMinusDstColor`

One minus the destination color.


### `dstAlpha`

The destination alpha.


### `oneMinusDstAlpha`

One minus the destination alpha.


### `srcAlphaSaturated`

The smaller of the source alpha and one minus the destination alpha.


### `blendColor`

The pass blend color, set with `setBlendColor` on the pass.


### `oneMinusBlendColor`

One minus the pass blend color, set with `setBlendColor` on the pass.
