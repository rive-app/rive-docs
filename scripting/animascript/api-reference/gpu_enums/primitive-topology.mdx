---
title: PrimitiveTopology
---

How a [GPUPipeline](/scripting/animascript/api-reference/gpu/gpu-pipeline) assembles vertices into primitives.


## Fields

### `pointList`

Each vertex is a point.


### `lineList`

Each pair of vertices is a line.


### `lineStrip`

Each vertex after the first extends a connected line.


### `triangleList`

Each three vertices form a triangle.


### `triangleStrip`

Each vertex after the first two forms a triangle with the two before it.
