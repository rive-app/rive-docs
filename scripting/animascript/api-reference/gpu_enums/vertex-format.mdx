---
title: VertexFormat
---

Format of one vertex attribute in a vertex buffer.


## Fields

### `float1`

One 32 bit float, `f32` in WGSL.


### `float2`

Two 32 bit floats, `vec2f` in WGSL.


### `float3`

Three 32 bit floats, `vec3f` in WGSL.


### `float4`

Four 32 bit floats, `vec4f` in WGSL.


### `uint8x4`

Four 8 bit unsigned integers, `vec4u` in WGSL.


### `sint8x4`

Four 8 bit signed integers, `vec4i` in WGSL.


### `unorm8x4`

Four 8 bit unsigned values read as 0 to 1, `vec4f` in WGSL.


### `snorm8x4`

Four 8 bit signed values read as -1 to 1, `vec4f` in WGSL.


### `uint16x2`

Two 16 bit unsigned integers, `vec2u` in WGSL.


### `sint16x2`

Two 16 bit signed integers, `vec2i` in WGSL.


### `unorm16x2`

Two 16 bit unsigned values read as 0 to 1, `vec2f` in WGSL.


### `snorm16x2`

Two 16 bit signed values read as -1 to 1, `vec2f` in WGSL.


### `uint16x4`

Four 16 bit unsigned integers, `vec4u` in WGSL.


### `sint16x4`

Four 16 bit signed integers, `vec4i` in WGSL.


### `float16x2`

Two 16 bit floats, `vec2f` in WGSL.


### `float16x4`

Four 16 bit floats, `vec4f` in WGSL.


### `uint32`

One 32 bit unsigned integer, `u32` in WGSL.
