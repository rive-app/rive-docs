---
title: CompareFunction
---

Comparison for the depth test and for comparison samplers, as in shadow maps. A
test passes when the comparison of the new value against the stored one holds.


## Fields

### `none`

No comparison. A sampler with it filters normally.


### `never`

Never passes.


### `less`

Passes when the new value is less.


### `equal`

Passes when the values are equal.


### `lessEqual`

Passes when the new value is less or equal.


### `greater`

Passes when the new value is greater.


### `notEqual`

Passes when the values differ.


### `greaterEqual`

Passes when the new value is greater or equal.


### `always`

Always passes.
