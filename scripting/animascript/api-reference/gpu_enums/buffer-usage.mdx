---
title: BufferUsage
---

How a [GPUBuffer](/scripting/animascript/api-reference/gpu/gpu-buffer) will be used. Pass it to the [GPUBuffer](/scripting/animascript/api-reference/gpu/gpu-buffer) constructor.


## Fields

### `vertex`

Vertex data, bound with `setVertexBuffer` on a [GPURenderPass](/scripting/animascript/api-reference/gpu/gpu-render-pass).


### `index`

Index data, bound with `setIndexBuffer` on a [GPURenderPass](/scripting/animascript/api-reference/gpu/gpu-render-pass).


### `uniform`

Uniform data, bound with a [GPUBindGroupUBO](/scripting/animascript/api-reference/gpu/gpu-bind-group-ubo).
