---
title: TextureViewDimension
---

How a [GPUTextureView](/scripting/animascript/api-reference/gpu/gpu-texture-view) reads its texture. Set it on [GPUTextureViewDesc](/scripting/animascript/api-reference/gpu/gpu-texture-view-desc).


## Fields

### `texture2D`

A single 2D texture or layer.


### `cube`

A cube map.


### `texture3D`

A 3D texture.


### `array2D`

An array of 2D layers.


### `cubeArray`

An array of cube maps.
