---
title: TextureAspect
---

Which planes of a depth stencil texture a [GPUTextureView](/scripting/animascript/api-reference/gpu/gpu-texture-view) exposes.


## Fields

### `all`

Every plane the format has.


### `depthOnly`

Depth only. Use it for a view sampled as `texture_depth_2d` in WGSL.


### `stencilOnly`

Stencil only.
