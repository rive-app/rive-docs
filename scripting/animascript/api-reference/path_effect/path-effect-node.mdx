---
title: PathEffectNode
---

The shape a [PathEffect](/scripting/animascript/api-reference/host/path-effect) applies to, passed to its `update` alongside the
path: the stroke or fill being drawn, and the shape's transform.

The paint is a snapshot of the stroke or fill: its style, thickness, cap,
join, solid color, feather and blend mode. Gradients are not included.
```as
override update(path: Path, node: PathEffectNode): Path {
    let paint = node.asPaint();
    this.spacing = paint.thickness * 2;
    return path;
}
```

## Methods

### `asPaint`

<div class="signature">
```as
asPaint(): Paint
```
</div>

Returns the stroke or fill the effect applies to, the same as
`paint`.


### `position`

<div class="signature">
```as

```

The shape's position in its parent's space.
```as
let center = node.position();
```


### `setPosition`

<div class="signature">

</div>

### `scale`

<div class="signature">


The shape's scale.


### `setScale`

<div class="signature">
```as
setScale(value: Vector): void
```

Sets the shape's scale.


### `worldTransform`

<div class="signature">
```as
unsafe worldTransform(): Mat2D
```
</div>

The shape's transform in artboard space, for example to place the
effect's geometry in world coordinates.
```as
let toWorld = node.worldTransform();
```


### `setWorldTransform`

<div class="signature">
```as
unsafe setWorldTransform(value: Mat2D): void
```
</div>

Sets the shape's transform in artboard space.


### `decompose`

<div class="signature">
```as
unsafe decompose(worldTransform: Mat2D): void
```
</div>

Sets the shape's position, rotation and scale so that its world
transform becomes `worldTransform`.
