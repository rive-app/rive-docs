---
title: VertexBuffer
---

Stores a list of 2D vertex positions for use with image meshes, drawn by
`Renderer.drawImageMesh` and `Renderer.drawImageMeshInstanced`. The same
type holds the texture coordinates.
```as
let vertices = new VertexBuffer();
vertices.add3(Vector.xy(0, 0), Vector.xy(100, 0), Vector.xy(100, 100));
let uvs = new VertexBuffer();
uvs.add3(Vector.xy(0, 0), Vector.xy(1, 0), Vector.xy(1, 1));
let triangles = new TriangleBuffer();
triangles.add(0, 1, 2);
```


## Fields

### `length`

<div class="signature">
```as
readonly length: i32
```
</div>

Number of vertices in the buffer.


## Methods

### `add`

<div class="signature">
```as
add(v: Vector): void
```
</div>

Adds a vertex to the buffer.
```as
let vb = new VertexBuffer();
vb.add(Vector.xy(0, 0));
```


### `add2`

<div class="signature">
```as
add2(a: Vector, b: Vector): void
```
</div>

Adds two vertices to the buffer.


### `add3`

<div class="signature">
```as
add3(a: Vector, b: Vector, c: Vector): void
```
</div>

Adds three vertices to the buffer.
```as
let vb = new VertexBuffer();
vb.add3(Vector.xy(0, 0), Vector.xy(1, 0), Vector.xy(1, 1));
```


### `reset`

<div class="signature">
```as
reset(): void
```
</div>

Clears all vertices from the buffer.
```as
let vb = new VertexBuffer();
vb.reset();
```
