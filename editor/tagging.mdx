Tags help you organize a file. Create a tag, assign it to items such as bones, groups, View Models, assets, or animations, then use it to filter a panel, lock objects on the stage, or select everything that shares the tag.

Tags belong to the file, not to a single artboard. Any tag you create is available on every artboard and in every panel that supports tags: the [Hierarchy](/editor/interface-overview/hierarchy), Data, Assets, and Animations panels.

## Creating tags

You can create a tag from the [Inspector](/editor/interface-overview/inspector), from a panel's tags menu, or while assigning it to an item.

### From the Inspector

<Steps>
  <Step>
    Click an empty area of the stage so nothing is selected.
  </Step>
  <Step>
    In the **Tags** section of the Inspector, click **+**.
  </Step>
  <Step>
    Enter a name for the tag, then click the color swatch to choose its color.
  </Step>
</Steps>

<VideoEmbed src="https://static.rive.app/video/new-tag-from-inspector.mp4" />

You can come back here at any time to rename a tag, change its color, or drag tags to reorder them. To delete a tag, right-click it and remove it.

### From the tags menu

Open the context menu in the header of the Hierarchy, Data, Assets, or Animations panel, then select **Create Tag**. The new tag appears in the Inspector, where you can rename it and set its color.

<VideoEmbed src="https://static.rive.app/video/new-tag-from-sidebar.mp4" />

### While assigning a tag

<Steps>
  <Step>
    Select one or more items on the stage or in a panel.
  </Step>
  <Step>
    Right-click the selection and open **Add Tag**.
  </Step>
  <Step>
    Select an existing tag, or select **New Tag** to create one and assign it in a single step.
  </Step>
</Steps>

<VideoEmbed src="https://static.rive.app/video/new-tag-from-elements.mp4" />

To remove a tag from an item, right-click it and select the tag under **Remove Tag**.

## Using the tags menu

Each panel that supports tags has a **Tags** section in its header context menu. It includes these options:

- **Create Tag** adds a new tag to the file.
- **Edit Tags** clears the selection so you can edit tags in the Inspector.
- **Collapse Tags** / **Reveal Tags** hides or shows tag names next to tagged items.
- A submenu for each tag with **Filter**, **Lock**, and **Select**.

![Hierarchy context menu showing the Tags section, with a tag's Filter, Lock, and Select submenu open](/images/editor/tagging/tags-menu.png)

### Collapsing tags

Tagged items show the tag's color and name to the right of the item.

<VideoEmbed src="https://static.rive.app/video/tags-collapse-reveal.mp4" />

Select **Collapse Tags** to hide the names and show only the colors. Select **Reveal Tags** to show the names again. This setting applies to the whole file.

### Filtering by tag

Open a tag's submenu and check **Filter** to show only the items that have that tag. Active filters appear next to the panel name.

<VideoEmbed src="https://static.rive.app/video/tags-filter.mp4" />

You can filter by as many tags as you want. An item stays visible if it has any of the filtered tags. Each panel has its own filters, so filtering the Hierarchy doesn't affect the Data, Assets, or Animations panels.

To clear every filter in a panel, select **Remove filters** from the tags menu.

<Tip>Filter by tag to show only the controls you need while animating, such as the bones and targets of a character rig.</Tip>

### Locking by tag

Open a tag's submenu in the Hierarchy and check **Lock** to lock every object with that tag. You can't select a locked object on the stage. You can also lock or unlock a tag with the lock icon next to it in the Inspector.

Locking is only available in the Hierarchy. Use it when you hand off a file to another animator, so they don't move objects that shouldn't change.

### Selecting by tag

Open a tag's submenu and select **Select** to select every item in that panel with the tag. In the Inspector, click the target icon next to a tag to select every tagged object on the stage.
