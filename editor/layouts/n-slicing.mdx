When artwork is resized, everything in it stretches, including details that should stay the same size, such as rounded corners or a decorative border. N-Slicing divides artwork into segments and decides which ones stay fixed and which ones scale, so it can resize without distorting.

N-Slicing is based on 9-slicing, a technique common in game design. A 9-slice divides an image into nine segments. The four corners keep their size, and the edges and center stretch or tile to fill the space. Rive's N-Slicing works the same way, but you can create any number of segments, on both images and vector artwork.

## N-Slicing in responsive designs

N-Slicing is useful for artwork that needs to fit a Layout, such as a button background, a speech bubble, or a panel frame. Place an N-Slice directly inside a Layout, and it resizes to fill that Layout while its fixed segments keep their size. See [What takes part in a Layout](/editor/layouts/layouts-overview#what-takes-part-in-a-layout).

## Creating an N-Slice

You can apply an N-Slice to an image, to a group of vector objects, or to a component instance.

### On an image

<Steps>
  <Step>
    Select the image.
  </Step>
  <Step>
    In the **Deform** section of the **Inspector**, click **+** and select **N-Slice**. You can also right-click the image on the stage or in the **Hierarchy** and select **Deform** > **N-Slice**.
  </Step>
  <Step>
    Position the axes and set the tile modes. See [Setting up an N-Slice](#setting-up-an-n-slice).
  </Step>
  <Step>
    Click **Done** in the **Inspector** or on the stage.
  </Step>
</Steps>

### On vector artwork

<Steps>
  <Step>
    Select the artwork. If it's already in a group, select the group and click **Convert to N-Slice** in the **Inspector**. Otherwise, select the objects and click **N-Slice selection** in the **Inspector**, or right-click them and select **Wrap in** > **N-Slice**.
  </Step>
  <Step>
    With the N-Slice group selected, click **Edit N-Slice** in the **Inspector** or press <kbd>Enter</kbd>.
  </Step>
  <Step>
    Position the axes. See [Setting up an N-Slice](#setting-up-an-n-slice).
  </Step>
  <Step>
    Click **Done** in the **Inspector** or on the stage.
  </Step>
</Steps>

### On a component instance

A [component](/editor/fundamentals/components#deform) instance with **Mode** set to **Node** can take an N-Slice the same way an image can. The component draws its artboard as a flat image and slices that image, so, like an image, it can look soft when scaled up.

<Steps>
  <Step>
    Select the component instance and set **Mode** to **Node**.
  </Step>
  <Step>
    In the **Deform** section of the **Inspector**, click **+** and select **N-Slice**.
  </Step>
  <Step>
    Position the axes and set the tile modes the same way you would for an image.
  </Step>
</Steps>

## Setting up an N-Slice

To change an N-Slice, select it and click **Edit N-Slice** in the **Inspector**, right-click it and select **Edit N-Slice**, or press <kbd>Enter</kbd>.

<Note>
  Set up your N-Slice before resizing the image or group. You can adjust axes on artwork that's already been resized, but it's harder to position new ones accurately.
</Note>

### Fixed and scaling segments

Segments alternate between fixed and scaling, starting with a fixed segment. In a 9-slice, that means fixed, then scaling, then fixed, along both the horizontal and vertical axes.

In edit mode, fixed segments have solid blue borders, and scaling segments have dashed borders.

### Positioning axes

A new N-Slice has four axes, two vertical and two horizontal, which divide the artwork into nine segments. Drag an axis to move it, or enter its position in the **Inspector** in points or as a percentage.

To add an axis, drag inward from one of the white handles on the edges of the artwork. A new axis is created with a mirrored partner on the opposite side, which keeps the fixed and scaling segments alternating. To create a single axis instead, hold <kbd>Cmd</kbd> (macOS) or <kbd>Ctrl</kbd> (Windows) before you start dragging.

### Setting tile modes

Tile modes control how a scaling segment fills its space. They're only available on images and component instances.

- **Stretch:** The segment stretches to fill the space.
- **Repeat:** The segment tiles to fill the space.
- **Hidden:** The segment isn't drawn.

**Hidden** also works on fixed segments. **Stretch** and **Repeat** have no effect on them, because fixed segments don't change size.

<Steps>
  <Step>
    Open the N-Slice's edit mode.
  </Step>
  <Step>
    Click a segment on the stage. Its tile is highlighted in the **Inspector**.
  </Step>
  <Step>
    Select a tile mode from the dropdown in the **Inspector**.
  </Step>
</Steps>
