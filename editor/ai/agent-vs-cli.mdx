There are two ways to have AI build with Rive:

- The **[AI Agent](/editor/ai-agent/ai-agent)** is built into the Rive Editor and works in the file you have open.
- The **[Rive CLI](/cli/overview)** lets your own coding agent, such as Claude Code or Cursor, build Rive projects on disk.

| | AI Agent | Rive CLI |
| --- | --- | --- |
| **Where you prompt** | Inside the Rive Editor | Your own coding agent, such as Claude Code or Cursor |
| **What it changes** | The file open in the Editor | Project files on disk, which build to `.riv` and `.rev` files |
| **Model and billing** | Rive credits, or your workspace's own API keys | Your coding agent's plan |
| **Best for** | Quick help while you design, animate, and code in the Editor | Working from your code editor, version control, and CI, without opening the Editor |
