Every [path](/editor/fundamentals/shapes-and-paths-overview) is made of vertices. Edit Vertices mode lets you move each vertex, change the curve between vertices with bezier handles, and change the path as a whole. You can edit vertices in Design mode, or in Animate mode to key them.

## Editing vertices

<Steps>
  <Step>
    Enter Edit Vertices mode in any of these ways:

    - Select a path and press `Enter`. With a shape selected, press `Enter` twice.
    - Double-click a path on the stage. If it's inside a shape, double-click the shape first.
    - Click **Edit Vertices** in the **Deform** section of the Inspector.
  </Step>
  <Step>
    Select a vertex and drag it, or drag its bezier handles. Shift-click or drag a selection box to select several vertices.
  </Step>
  <Step>
    To finish, click **Done Editing** in the Inspector or double-click an empty area of the stage.
  </Step>
</Steps>

<VideoEmbed src="https://static.rive.app/video/edit-vertices.mp4" />

Paths drawn with a [Shape tool](/editor/fundamentals/procedural-shapes) have no vertices to edit until you convert them to custom paths. When you enter Edit Vertices mode on one, Rive asks you to convert it. Converting removes its procedural properties, such as width, height, and number of points, along with any keys on them.

To add or delete vertices, use the [Pen Tool](/editor/fundamentals/pen-tool-overview#adding-vertices-to-a-path).

<Tip>
  Use [Deep Select](/editor/interface-overview/selection-and-navigation#deep-select) to select a path inside nested groups on the stage.
</Tip>

## Vertex types

Select one or more vertices to change their type at the top of the vertex properties in the Inspector. The type decides how the vertex's bezier handles behave.

| Type | Handles |
| --- | --- |
| **Straight** | No handles. The segments on each side are straight lines, and you can round the corner with **Corner**. |
| **Mirrored** | The two handles share the same angle and length. This is the default when you click and drag with the Pen Tool. |
| **Detached** | Each handle has its own angle and length. |
| **Asymmetric** | The two handles share the same angle, but each has its own length. |

To switch types without the Inspector, see the [Pen Tool shortcuts](/editor/fundamentals/pen-tool-overview#path-and-vertex-shortcuts).

### Vertex properties

- **Position**: The vertex's X and Y position.
- **Corner**: The corner radius of a Straight vertex.
- **Bezier**: The angle and length of the handles. Mirrored vertices have one angle and length, Asymmetric vertices have an angle with separate in and out lengths, and Detached vertices have an angle and length for each handle.

## Path options

The path options at the top of the Inspector apply to the whole path.

- **Done Editing**: Exits Edit Vertices mode.
- **Open Path** / **Close Path**: Disconnects the last vertex from the first, or connects them.
- **Reverse Direction**: Reverses the order of the vertices. The direction of a path decides how it's filled when it overlaps other paths in its shape. See [Fill rules](/editor/fundamentals/fill-and-stroke#fill-rules).
- **Convert Radial Corners**: Replaces rounded corners with real vertices. See [Convert Radial Corners](#convert-radial-corners).
- **Simplify**: Reduces the number of vertices. See [Simplify](#simplify).
- **Key All Vertices** and **Key Selected Vertices**: In Animate mode, key every vertex in the path, or only the selected vertices. Press `Shift + K` to key all vertices.

### Convert Radial Corners

A rounded corner on a Straight vertex is calculated from its **Corner** value, so it stretches when you scale the path or shape unevenly. **Convert Radial Corners** replaces each rounded corner with two curved vertices, so it scales like the rest of the path.

It converts the selected vertices, or every vertex in the path if none are selected.

![Convert Radial Corners button in the path options converts a single rounded corner into two vertices on the stage](/images/editor/edit-vertices/convert-radial-corners.gif)

### Simplify

Use **Simplify** to reduce the number of vertices in a path while keeping its overall shape. It's useful for paths drawn with the [Pencil](/editor/design/freehand-drawing) or imported from an [SVG](/editor/assets/svg).

<VideoEmbed src="https://static.rive.app/video/simplify-path.mp4" />

- **Tolerance**: How far the simplified path can move from the original. Higher values remove more vertices.
- **Corner Angle**: Vertices that turn at least this much are kept as corners. Rounded corners and the vertices next to them are always kept.
- **Straight Lines**: Removes curve handles and corner radii, so only straight segments remain.

The stage previews the result, and the Inspector shows the number of vertices before and after. Click **Simplify Path** to apply it, or select vertices first and click **Simplify Selected** to simplify only those.

Simplify only works in Design mode. If a removed vertex has keys, its keys are removed too, and if the path is bound to bones, the removed vertices' weights are removed.
