Use the **Pen Tool** to draw custom vector paths one vertex at a time. It gives you precise control over every point and curve.

<Tip>
For common shapes such as rectangles and ellipses, use the [Shape tools](/editor/fundamentals/procedural-shapes) instead. To draw freehand, use the [Pencil](/editor/design/freehand-drawing).
</Tip>

## Drawing a path

<Steps>
  <Step>
    Select the **Pen Tool** from the Create Tools menu, or press <kbd>P</kbd>.
  </Step>
  <Step>
    Click the stage to place straight vertices. Click and drag to place a vertex with mirrored bezier handles.
  </Step>
  <Step>
    Click the first vertex to close the path, or press <kbd>Esc</kbd> to finish with an open path.
  </Step>
</Steps>

![Clicking with the Pen Tool to place straight vertices](/images/editor/fundamentals/pen-tool-create.gif)

![Clicking and dragging with the Pen Tool to create curved vertices with bezier handles](/images/editor/fundamentals/pen-tool-create-handless.gif)

<Tip>While dragging out a new vertex, hold <kbd>Alt</kbd>/<kbd>Opt</kbd> to detach its handles. This lets you make a sharp change of direction between two curves.</Tip>

To keep drawing an open path later, select it, press <kbd>Enter</kbd> to edit its vertices, then click its last vertex with the Pen Tool. To open a closed path, use **Open Path** in [Edit Vertices](/editor/fundamentals/edit-vertices).

## Adding vertices to a path

With the Pen Tool active, move the pointer over a segment of a path you're editing. The pointer snaps to the segment, and a click splits it with a new vertex at that point. Drag right after clicking to move the new vertex.

## Path and vertex shortcuts

These shortcuts work with the Pen Tool. Shortcuts marked "Pen or Select" also work with the Select tool while you edit vertices.

| Shortcut | Target | Tool | Result |
| --- | --- | --- | --- |
| <kbd>Cmd</kbd>/<kbd>Ctrl</kbd> + click | Vertex | Pen or Select | Toggle between straight and mirrored handles |
| <kbd>Cmd</kbd>/<kbd>Ctrl</kbd> + drag | Vertex | Pen or Select | Pull out mirrored bezier handles |
| <kbd>Cmd</kbd>/<kbd>Ctrl</kbd> + click | Handle | Pen or Select | Remove the handle |
| <kbd>Alt</kbd>/<kbd>Opt</kbd> + click | Handle | Pen or Select | Detach the handle from its partner |
| <kbd>Alt</kbd>/<kbd>Opt</kbd> or <kbd>Cmd</kbd>/<kbd>Ctrl</kbd> + drag | Handle | Pen or Select | Detach the handle and drag it freely |
| <kbd>Alt</kbd>/<kbd>Opt</kbd> + click | Vertex | Pen | Delete the vertex |

To learn more about straight, mirrored, and detached handles, and the other path options, see [Edit Vertices](/editor/fundamentals/edit-vertices).
