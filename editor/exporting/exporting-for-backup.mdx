<Note>
A backup is a snapshot, so it doesn't stay in sync with the original file. Depending on what you need, another option may suit you better:

- **To share a file with someone,** [invite them](/editor/interface-overview/toolbar#invite) to the file, or add them to the project that contains it. They'll always see the latest version.
- **To keep a file in source control,** use the [Rive CLI](/cli/overview) to convert it to [Rive Markup Language (RML)](/runtimes/advanced-topic/rml), a text format that diffs and merges like code and stays linked to the original file.
- **To go back to an earlier version of a file,** use [Revision History](/editor/fundamentals/revision-history).
</Note>

A backup is a `.rev` file: a complete copy of a Rive file that you can import back into the Editor and keep editing. Unlike a [runtime export](/editor/exporting/exporting-for-runtime) (`.riv`), which strips out everything your app doesn't need, a backup keeps all of the Editor data.

Export a backup when you want to:

- Keep a local copy of a file on your computer.
- Send a file to Rive support with a support ticket.

Exporting and importing backups are available on paid plans. [Learn more about our plans and pricing](https://rive.app/pricing?utm_source=docs&utm_medium=content).

## Exporting from the File Browser

<Steps>
  <Step>
    In the [File Browser](/editor/interface-overview/file-browser), find the file you want to back up.
  </Step>
  <Step>
    Right-click the file and select **Download Backup** to download the current version.

    To download an earlier version instead, open **Download Revision** and select a revision.
  </Step>
</Steps>

![Download Backup in the File Browser right-click menu](/images/editor/exporting/download-backup-file-browser.gif)

## Exporting from an open file

<Steps>
  <Step>
    Open the Editor Menu.
  </Step>
  <Step>
    Select **Export** > **For Backup**.
  </Step>
</Steps>

![Export For Backup in the Editor Menu](/images/editor/exporting/export-for-backup-editor-menu.gif)

## Importing a backup

<Steps>
  <Step>
    Open the File Browser and go to the project or folder where you want the file.
  </Step>
  <Step>
    Drag the `.rev` file from your computer into the File Browser.
  </Step>
</Steps>

The backup is imported as a new file. It doesn't replace or update the original.
