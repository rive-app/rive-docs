<Note>Every plan can export for runtime. On the Free plan, exported files play a Rive splash screen; paid plans export without it. [Learn more about our plans and pricing](https://rive.app/pricing?utm_source=docs&utm_medium=content).</Note>

A `.riv` file is the production-ready version of your Rive file. It isn't a design file, a mockup, or a prototype to hand off and rebuild. It's the final asset that ships in your product. Your artboards, animations, state machines, data binding, and scripts all run at runtime exactly as you built them.

The same `.riv` file works across every supported runtime, including web, mobile, and game engines. Load it with any of Rive's [open source runtimes](/runtimes/).

## Exporting a .riv file

<YouTube id="H_px35jTqhg" />

<Steps>
  <Step>
    Click **Publish** on the right side of the toolbar and choose **To .riv**.

    You can also open the main menu in the left of the toolbar and choose **Export** > **For Runtime**.
  </Step>
  <Step>
    In the dialog that opens, click **Export your Rive file**.

    On a paid plan, turn on **Skip this modal next time** to export directly in the future.
  </Step>
  <Step>
    Add the downloaded `.riv` file to your app, game, or website, and load it with a [runtime](/runtimes/).
  </Step>
</Steps>

<Tip>
  To save an editable copy of your file, export it **For Backup** as a `.rev` file instead.
</Tip>

## Using newer files with older runtimes

Rive files are built for backwards compatibility. A file exported from the latest version of the editor can still load in older runtimes.

If a file uses a feature that was added after your runtime version was released, that specific feature may be skipped, while the rest of the file continues to run.

For full [feature support](/feature-support), fixes, and performance improvements, keep your runtime up to date.
