Rive is built for interactive animation, but sometimes you need a traditional format such as an MP4, a GIF, or a PNG. The Cloud Renderer creates these files on Rive's servers, so you can keep working while your render runs.

Rendering has two parts:

- **Render presets** are saved settings for a render, such as what to render, the format, and the size. They belong to an artboard.
- The **Render Queue** is where you start renders and download the finished files.

## Supported formats

The available formats depend on the preset's mode.

| Mode | Formats |
| --- | --- |
| **Design** (a still image) | PNG, SVG |
| **Animation** or **State Machine** (over time) | H.264 (`.mp4`), WebM, GIF, PNG sequence, SVG sequence |

PNG and SVG sequences download as a `.zip` file with one image per frame.

## Creating a render preset

<Steps>
  <Step>
    Select the artboard you want to render.
  </Step>
  <Step>
    In the **Render Presets** section of the Inspector, click **+**.

    ![Render Presets section in the Inspector](/images/editor/exporting/render-presets-inspector.webp)
  </Step>
  <Step>
    Click the options icon to the left of the preset name, then set the preset's options.

    ![Render preset options for an Animation preset](/images/editor/exporting/render-preset-options.gif)
  </Step>
</Steps>

You can change a preset's format at any time from the dropdown next to its name.

![Format dropdown on a Design preset showing PNG and SVG](/images/editor/exporting/render-preset-design-format.webp)

### Preset options

- **Name**: The name of the preset.
- **Mode**: What to render.
  - **Design** renders a still image of the artboard.
  - **Animation** renders a single timeline. Choose it under **Timeline**.
  - **State Machine** renders a State Machine as it plays over time. Choose it under **State Machine**.
- **Format**: The file format. For Animation and State Machine presets, also set the frame rate.
- **Duration**: How long to render, plus a multiplier (**1x**, **2x**, **3x**, or a custom value). Available for Animation and State Machine presets.
- **Bit rate**: The video quality for H.264 and WebM. Leave it on **Auto**, or enter a custom value in kbps.
- **Size**: Use **Auto** to render at the artboard's size, or choose a custom width and height.

## Rendering

<Steps>
  <Step>
    Add presets to the Render Queue in any of these ways:

    - Click **Queue All** below the presets to add every preset on the artboard.
    - In a preset's options, click **Add to Render Queue**.
    - To add a preset and start rendering right away, click **Queue and Start Render** in the preset's options, or click the play button next to the preset's name.

    The Render Queue opens when you add a preset.

    ![Render Queue open next to the Hierarchy](/images/editor/exporting/render-queue-open.webp)
  </Step>
  <Step>
    On the **Queued** tab, check each render's settings. Expand a render to change its options for that render only, such as **Matte**, the background color, or the **View Model** instance to render with.
  </Step>
  <Step>
    Click the play button next to a render to start it, or click the double play button at the top of the Render Queue to start every queued render.

    ![Queued tab of the Render Queue](/images/editor/exporting/render-queue-queued.webp)
  </Step>
  <Step>
    When a render finishes, open the **Completed** tab and click the download button next to it.

    ![Completed tab of the Render Queue with the download button](/images/editor/exporting/render-queue-completed.webp)
  </Step>
</Steps>

To reopen the Render Queue later, open the Editor Menu and select **Open Render Queue**.

<Tip>You can also add a timeline straight to the Render Queue: right-click it in the Animations list and select **Add to Render Queue**.</Tip>
