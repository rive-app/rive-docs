When you set two keys on a property, Rive calculates the values in between. This is called interpolation. The interpolation type, often called easing, controls how the value gets from one key to the next: at a steady rate, speeding up and slowing down, bouncing past the target, or jumping straight to it.

Interpolation is set on the key where a change starts, and applies until the next key.

## Interpolation types

<RiveEmbed src="https://static.rive.app/rivs/easing.riv" aspectRatio="608 / 188" />

- **Hold** doesn't interpolate. It keeps the current value until the next key, then jumps to the new value instantly.
- **Linear** changes the value at a constant rate. It's the default for new keys.
- **Cubic** follows a curve that you shape with two handles. The default curve changes slowly at the start and end and fastest in the middle. Cubic always moves between the values you keyed and never past them.
- **Cubic Value** is like Cubic, but you shape it with Bezier handles in the [Graph Editor](/editor/animate-mode/graph-editor), and the curve can overshoot a key's value before settling on it.
- **Elastic** overshoots the value and oscillates before settling on it, like a spring.

| Shortcut | Interpolation |
| --- | --- |
| <kbd>F6</kbd> | Hold |
| <kbd>F7</kbd> | Linear |
| <kbd>F8</kbd> | Cubic, ease in and out |
| <kbd>Shift</kbd> + <kbd>F8</kbd> | Cubic, ease in |
| <kbd>Cmd/Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>F8</kbd> | Cubic, ease out |
| <kbd>F9</kbd> | Cubic Value, ease in and out |
| <kbd>Shift</kbd> + <kbd>F9</kbd> | Cubic Value, ease in |
| <kbd>Cmd/Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>F9</kbd> | Cubic Value, ease out |
| <kbd>F10</kbd> | Elastic |

## Setting the interpolation on keys

<Steps>
  <Step>
    Select one or more keys on the timeline.
  </Step>
  <Step>
    Choose an interpolation type at the top of the Interpolation panel, to the right of the timeline. The same options are in the **Keyframe Interpolation** section of the Inspector.

    ![Interpolation panel to the right of the timeline, showing a Linear curve](/images/editor/animate-mode/interpolation-panel.webp)

    You can also right-click the keys and choose a type from the **Interpolation** menu, or use one of the [shortcuts](#interpolation-types).
  </Step>
  <Step>
    Adjust the curve or options for the type you chose. See below.
  </Step>
</Steps>

<Tip>If the Interpolation panel is hidden, click the curve icon next to the timeline tabs to show it.</Tip>

The graph in the Interpolation panel shows how the value changes from the selected key to the next one. Time runs along the horizontal axis, and the change in value runs up the vertical axis.

### Cubic options

Drag the two handles on the graph to shape the curve. You can drag them as far as you want up or down; the graph zooms out to keep them in view.

The field below the graph shows the curve as four numbers: the horizontal and vertical positions of the first handle, then the second, like a CSS `cubic-bezier()` value. Type your own values, separated by commas or spaces, to match an easing from a brand's motion guidelines or another tool. You can also copy them to reuse elsewhere.

![Editing the cubic values field below the interpolation graph](/images/editor/animate-mode/interpolation-values-field.gif)

### Cubic Value options

Shape Cubic Value curves by dragging their handles in the [Graph Editor](/editor/animate-mode/graph-editor). In the Interpolation panel, you can click **Open graph editor**, or turn on **Apply auto bezier** to set the handles automatically for a smooth curve through the surrounding keys. **Auto bezier coefficient** controls how strong that curve is.

### Elastic options

- **Easing**: Where the oscillation happens. **Ease In** oscillates at the start, **Ease Out** at the end, and **Ease In Out** at both.
- **Amplitude**: How far the value overshoots.
- **Period**: How quickly the oscillation settles.

## Default interpolation

The default interpolation is the type that new keys use. It starts as Linear.

To set it from a key:

<Steps>
  <Step>
    Select a key that uses the interpolation you want.
  </Step>
  <Step>
    In the Interpolation panel, click **Set as default**.

    ![Set as default button in the interpolation options](/images/editor/animate-mode/interpolation-set-as-default.png)
  </Step>
</Steps>

To set it from the Inspector:

<Steps>
  <Step>
    Deselect everything. The Inspector shows **Default Interpolation**.
  </Step>
  <Step>
    Choose the interpolation type and options you want new keys to use.

    ![Default Interpolation options in the Inspector](/images/editor/animate-mode/interpolation-set-default.png)
  </Step>
</Steps>

## The Graph Editor

To see and edit interpolation as curves on a graph, use the [Graph Editor](/editor/animate-mode/graph-editor).
