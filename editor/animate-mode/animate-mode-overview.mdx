Animation in Rive is built from a few parts that work together:

- A **[timeline](/editor/animate-mode/timeline)** is a single animation, such as an idle loop or a button press.
- **[Keys](/editor/animate-mode/keys)** on a timeline store a property's value at a point in time, like a ball's Y position at frame 0 and frame 30.
- **[Interpolation](/editor/animate-mode/interpolation-easing)** fills in the values between two keys, and decides how the motion eases. Use the [Graph Editor](/editor/animate-mode/graph-editor) to shape it as a curve.
- A **[state machine](/editor/state-machine/state-machine)** decides which timelines play at runtime, and blends and transitions between them in response to data and user input.

You create timelines, keys, and state machines in Animate mode. Switch modes with the toggle in the toolbar, or press `Tab`. See [Design and Animate Modes](/editor/fundamentals/design-vs-animate-mode).

<Warning>
  In Animate mode, editing an object while a timeline is selected can create keys. Make design changes in Design mode instead.
</Warning>

## Motion without keys

Not all motion needs keys. These features move objects on their own, or drive timelines for you:

- **[Constraints](/editor/constraints/constraints-overview)**: Make an object follow, aim at, or copy another object.
- **[Joysticks](/editor/manipulating-shapes/joysticks)**: Blend timelines from a single handle, such as turning a head.
- **[Data binding](/editor/data-binding/overview)**: Drive properties directly from values your app sets at runtime.
- **[Scripting](/scripting/getting-started)**: Animate with code.
