Rigging is the setup you do before animating, so the animating itself is easier. Instead of keying every vertex of an arm or every feature of a face, you build controls that move many things at once, then animate those controls.

A rig can be as simple as one object following another, or a full character with a skeleton, bending limbs, and a handle that turns its head. Most rigs combine several of these tools:

<CardGroup cols={2}>
  <Card title="Bones" icon="bone" href="/editor/manipulating-shapes/bones">
    Build a skeleton that moves objects as a hierarchy, and bend vector paths and images by binding them to bones.
  </Card>
  <Card title="Meshes" icon="draw-polygon" href="/editor/manipulating-shapes/meshes">
    Add vertices to a raster image so you can warp it, or bind it to bones so it bends.
  </Card>
  <Card title="Joysticks" icon="gamepad" href="/editor/manipulating-shapes/joysticks">
    Blend timelines with a single handle, to pose a head, eyes, or face from one control.
  </Card>
  <Card title="Constraints" icon="link" href="/editor/constraints/constraints-overview">
    Make an object follow, aim at, or copy another, without keying it.
  </Card>
</CardGroup>

## Choosing a tool

| To do this | Use |
| --- | --- |
| Move parts of a character together, like an arm and hand | [Bones](/editor/manipulating-shapes/bones) |
| Bend a vector shape, like a sleeve or a tail | [Bones](/editor/manipulating-shapes/bones#deforming-elements) bound to the path's vertices |
| Bend or warp an image | A [mesh](/editor/manipulating-shapes/meshes), on its own or bound to bones |
| Reach a target with a limb, like a foot on the ground | An [IK constraint](/editor/constraints/ik-constraint) |
| Keep an object within a distance of another, or on a path | A [distance](/editor/constraints/distance-constraint) or [follow path](/editor/constraints/follow-path-constraint) constraint |
| Copy another object's position, rotation, or scale | A [translation](/editor/constraints/translation-constraint), [rotation](/editor/constraints/rotation-constraint), [scale](/editor/constraints/scale-constraint), or [transform](/editor/constraints/transform-constraint) constraint |
| Pose a face or turn a head with one control | A [joystick](/editor/manipulating-shapes/joysticks) |
| Make Layout content scrollable | A [scroll constraint](/editor/constraints/scroll-constraint) |
